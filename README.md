# HAWT POTATO

A sendable potato. One holder. Don’t get cooked.

| --- | --- |

The pages live in [`docs/`](docs/) and publish with GitHub Pages from the `main` branch.

## GitHub Pages

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/docs**
4. Save
5. At your domain host, point `hawtpotato.app` (and `www` if you use it) to GitHub Pages
6. Until the custom domain is live, the same pages are at:
   - https://codeprater.github.io/HAWT-POTATO/privacy/
   - https://codeprater.github.io/HAWT-POTATO/terms/
   - https://codeprater.github.io/HAWT-POTATO/support/
